# NutriFit 🥗

### Smart Nutrition, Food Tracking & Meal Recommendation Android Application

NutriFit is an Android application designed to help users monitor their daily nutrition, track food consumption, calculate nutritional requirements, and discover meal recommendations based on their personal goals and available ingredients.

The application combines nutrition tracking, food management, barcode scanning, and rule-based meal recommendations into a simple and user-friendly mobile interface.

---

## 📱 Project Overview

Maintaining a balanced diet often requires users to understand their daily calorie requirements, monitor macronutrients, keep track of the foods they consume, and decide what meals are appropriate for their goals.

NutriFit provides these functions in one Android application.

The application can:

- Calculate estimated daily calorie requirements
- Track calories and macronutrients
- Record consumed foods
- Maintain food history
- Allow manual food entry
- Provide barcode-scanning support
- Recommend meals based on available ingredients
- Consider fitness/nutrition goals
- Consider preparation time
- Prioritize cuisine preferences
- Store nutrition history locally

## ✨ Features

### 🏠 Home Dashboard

The home dashboard provides a quick overview of the user's daily nutrition progress.

It displays:

- Calories consumed
- Protein consumed
- Carbohydrates consumed
- Fat consumed
- Daily nutrition progress
- Quick access to major application features

### 🧮 Nutrition Calculator

NutriFit estimates a user's nutritional requirements using personal information such as:

- Age
- Sex
- Height
- Weight
- Activity level
- Fitness goal

The application uses a BMR and TDEE-based calculation approach.
